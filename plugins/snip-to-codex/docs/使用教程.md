# 从下载到第一次发送：新手教程

这份教程不要求你会编程。完整的离线图文版位于下载包的 `docs/guide.html`，双击即可用浏览器打开。

## 1. 找到正确的下载包

打开本项目 GitHub 首页，在右侧找到 **Releases（发行版）**。窗口较窄时向下滚动。进入最新版本，在 **Assets（资源）** 区域下载 `SnipToCodex-v1.2.0-windows-x64.zip`。

不要选 `Source code`，它是给开发者的源码。本安装包面向 Windows 10 / 11 x64，不支持 macOS 和 Linux。截图工具不用注册账户；使用 AI 聊天仍需自己的账户。

## 2. 完整解压，双击安装

在“下载”文件夹找到 ZIP → 右键 → **全部解压缩** → **提取**。打开解压目录，双击 `Install.cmd`。它会复制程序并创建桌面和开始菜单快捷方式，无需管理员权限。

打开桌面的 **Snip to Codex**。想免安装使用，双击解压目录的 `Start.cmd`；请保留整个文件夹，不要只拷贝 exe。

Windows 可能显示未知发布者，因为项目目前没有商业代码签名。请确认文件来自本项目正式发行页；不确定来源时不要运行，也不必关闭安全防护。

![首次使用面板](../assets/welcome.png)

面板上可以直接点击 **开始截图**、**查看完整图文教程**、**打开截图文件夹**。

## 第一次截图前：设置自己的快捷键

1. 打开使用面板，点击 **更改快捷键**；托盘右键菜单也有这个入口。
2. 点击录入框，按下新组合，例如 **Ctrl + Shift + S**。
3. 点击 **保存**。新设置立即生效，下次启动仍会保留。

支持 Ctrl 或 Alt 搭配字母、数字、F1–F24，可额外加入 Shift。保存时会检查占用；冲突或保存失败时，原快捷键继续有效。**恢复默认** 会填入 Ctrl+Alt+S，点击保存后应用。

![快捷键设置](../assets/shortcut-settings.png)

## 点击输入栏旁的小剪刀

工具启动后，切回受支持的 Codex / ChatGPT 桌面版对话，输入栏旁会出现 **小剪刀**。点击它即可框选截图。

- 剪刀会跟随输入栏的位置；切到其他应用、最小化窗口或开始截图时隐藏。
- 小剪刀是独立的悬浮按钮，默认显示，可在使用面板取消勾选 **在对话输入栏旁显示小剪刀**。
- 只在能够识别当前桌面版输入栏时显示，网页版不显示。没有出现时仍可用快捷键或面板按钮截图。
- 定位只使用前台窗口和输入栏的位置，不读取输入文字，也不在后台连续截图。

![小剪刀示例位置](../assets/scissors.png)

## 3. 框选第一张图

先打开目标 Codex / ChatGPT 对话，再把报错、图表、文字等要截图的内容显示出来。

1. 按住 **Ctrl** 和 **Alt**，再按一下 **S**，然后松开按键。
2. 屏幕变暗，表示进入框选。
3. 按住鼠标左键，从要截区域的一角拖到另一角，再松开。
4. 明亮区域就是最终图片，绿色边框旁的数字是像素尺寸。
5. 按 **Enter**，或点击 **完成**。

![框选示例](../assets/selection.png)

框错了点击 **重新框选**，或重新拖动。放弃时按 **Esc** 或鼠标右键，取消后不会保存这次图片。图中是教学用模拟画面。

## 4. 看见缩略图，再发送

截图后会保存原图、复制到剪贴板，并尝试自动粘贴到桌面版聊天输入框。

**成功标准：输入框里出现图片缩略图。通知里显示已复制，不等于 AI 已收到。**

如果没有图片：切回正确的对话 → 点一下输入框 → 按 **Ctrl+V**。看到图片后输入问题，再点击聊天软件自己的发送按钮。

可以这样问：

> 请解释这条报错，并按步骤教我怎么解决。

> 请把图片中的文字整理成可以复制的内容。

> 帮我分析图表，哪些结论有数据支持？

工具不会自动点击发送，你可以先检查图片是否截多。

## 5. 网页版怎么用

先截图，再回到网页版聊天输入框，手动 **Ctrl+V**。自动定位只适配受支持的 Windows 桌面版，不会帮你选择浏览器标签页。目标网页和账户需要支持图片附件。

多个 Codex 窗口同时打开时，先激活目标窗口再用快捷键；无法确定目标时工具只复制，需手动粘贴。

只想截图、不想自动回到聊天？取消勾选面板的 **截图后尝试自动粘贴到 Codex**。

## 6. 退出、重启与找回图片

屏幕右下角时钟附近是系统托盘。点击旁边的 **^** 可以展开隐藏的小图标。右键截图工具图标，可打开使用面板、教程、截图文件夹，或退出工具。

关闭面板后快捷键仍有效；选择“退出”才会停止。退出后双击桌面快捷方式重启。

截图位于 `%LOCALAPPDATA%\SnipToCodex\Captures`。把它粘贴到文件资源管理器地址栏并回车，就能打开你自己电脑的保存目录。

## 7. 问题排查

| 问题 | 怎么处理 |
| --- | --- |
| 快捷键没反应 | 确认已启动；面板显示实际组合，冲突时改用 Ctrl+Alt+F8。也可点击“开始截图”。 |
| 有截图但没有附件 | 点聊天输入框再 Ctrl+V，或从截图文件夹用聊天附件按钮添加 PNG。 |
| 下载后没有 exe | 选 Releases 中 windows-x64 发行包，不是 Source code，并完整解压。 |
| 某些视频或系统界面黑屏 | 受保护画面可能无法截图，使用原程序导出功能，或用普通窗口测试。 |
| 程序报错 | 在 GitHub Issues 描述系统版本、操作步骤和错误；分享前遮住个人信息。 |

## 8. 更新与卸载

退出旧版，完整解压新版后运行 `Install.cmd` 即可更新。卸载时运行安装目录里的 `Uninstall.cmd`，之后手动删除程序文件夹。默认位置是 `%LOCALAPPDATA%\Programs\SnipToCodex`，截图会保留，按需自行清理。

默认不开机启动。若希望自动启动，按 Win+R 输入 `shell:startup`，把桌面快捷方式复制进去；移除这份启动快捷方式即可取消。快捷方式添加 `--quiet` 参数后，启动时只显示托盘。

## 9. 可选：让 Codex 主动看图

普通截图用户可以跳过。按照仓库首页的可选插件步骤安装，之后新建一条 Codex 任务。

说“帮我框选截图并分析”，会出现选区，由你选择并确认，Codex 再读取。说“读取我最近一次截取的图片”，会读取本工具截图目录中最新的图片，并应说明时间；时间不对时请重新截图。

插件不会后台持续监视桌面，也不会在原生输入栏添加按钮。

## 10. 图片和隐私

工具只在你触发时截图，确认后保存并复制；取消不保存。截图程序不联网上传、不收集遥测、不后台录屏。把图粘贴到聊天后，上传与处理遵循目标软件的行为；请求 Codex 读取本地图片时，图片会进入该任务上下文。

最近一次动作或错误记录在 `%LOCALAPPDATA%\SnipToCodex\status.txt`。向 GitHub Issues 分享前，检查其中的个人目录名称和截图内容。

社区项目，与 OpenAI 官方无隶属关系。
